Chrome Tab Discarder allows users to manually make Chrome tabs inactive and free up memory usage.

SETUP:
1. Download ZIP file and unzip
2. Go to chrome://extensions/ and turn on "Developer Mode"
3. In the top left, click on "Load Unpacked" and select the folder

USE:
Now, right click on desired tab and select "Pause Tab"
Also, click on extensions and pause tabs from the dropdown menu
